# AI-Powered E-Commerce Analytics

## Project Overview
This project focuses on analyzing e-commerce sales data to identify 
business insights, understand customer purchasing behavior, 
and evaluate sales performance using Python, SQL, and Power BI.


## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Jupyter Notebook

## Project Workflow

1. Data Understanding – Explored the dataset and identified data quality issues.
2. Data Cleaning – Handled missing values, duplicates, and data types.
3. Exploratory Data Analysis – Analyzed sales, products, customers, and regions.
4. SQL Analysis – Performed business queries to extract meaningful insights.
5. Data Visualization – Created charts to understand sales trends.
6. Power BI Dashboard – Built an interactive dashboard for business reporting.


## Key Business Insights

- Electronics generated the highest category revenue.
- Delivered orders accounted for 77.4% of total orders.
- Identified top-performing products and customers.
- Analyzed monthly sales trends and month-over-month growth.
- Compared revenue performance across different regions.
- Segmented customers based on their spending.


## Dataset
The project uses an e-commerce sales dataset containing order 
details, customer information, product categories, quantities, 
prices, discounts, regions, payment methods, and order statuses.


## How to Run

1. Clone this repository.
2. Install Python and the required libraries.
3. Open the notebooks folder in Jupyter Notebook or VS Code.
4. Run the notebooks in sequence.
5. Open the .pbix file using Power BI Desktop.
